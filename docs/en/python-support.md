# Python support

TrainLens 0.8.x supports CPython 3.11, 3.12, 3.13, and 3.14. The package metadata uses `>=3.11,<3.15`, and CI runs the full test, type-check, lint, build, and distribution-check workflow on every supported minor version.

Python 3.15 is intentionally not advertised while it remains a pre-release. Support can be added once the final release is available and the normal CI matrix passes on it.
