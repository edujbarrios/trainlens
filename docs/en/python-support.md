# Python support

TrainLens supports CPython **3.11, 3.12, 3.13, and 3.14**. The package metadata specifies `>=3.11,<3.15`, and CI tests each supported Python version.

The standard installation includes Matplotlib (plots) and ReportLab (PDF export). Python 3.15 is outside the current supported range; check the package metadata and CI for any future changes.
